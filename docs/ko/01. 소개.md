# 태고의 달인 비공식 레이팅 (rating.taiko.wiki)

[rating.taiko.wiki](https://rating.taiko.wiki)는 아케이드 '태고의 달인' 플레이어의 데이터를 바탕으로 실력을 객관적인 점수로 수치화하여 보여주는 비공식 레이팅 사이트입니다.

## 목표

프로젝트의 목표는 플레이어들의 실력을 비공식 레이팅을 통해 정량적으로 보여주고, 다양한 데이터 분석을 제공하는 것입니다. '동더 히로바'의 플레이 기록을 기반으로 당신의 실력을 정밀하게 분석하고, 다른 플레이어들과 비교해볼 수 있습니다.

## 주요 기능

- **레이팅 점수 계산**: '동더 히로바'의 데이터를 기반으로 유저의 종합적인 실력을 '레이팅 점수'로 계산합니다.
- **곡별 레이팅 점수**: 각 곡의 플레이 기록을 바탕으로 '곡 레이팅 점수'를 계산하여, 곡별 숙련도를 파악할 수 있습니다.
- **데이터 분석**: 산출된 레이팅 점수를 활용한 다각적인 실력 분석 데이터를 제공합니다.

## 수집하는 데이터

레이팅 계산을 위해 아래의 데이터를 수집합니다.

- **동더 히로바 프로필 정보**
    - 닉네임
    - 태고 번호 (북 번호)
    - 단위도장 합격 정보
    - 플레이 기록 요약
        - 클리어 / 풀콤보 / 전량(오니) 개수
        - 왕관(스코어 랭크)별 획득 개수
- **곡 플레이 상세 데이터**
    - 각 곡의 스코어, 클리어 종류(왕관), 스코어 랭크 등
