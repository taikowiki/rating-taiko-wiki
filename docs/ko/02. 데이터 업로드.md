# 데이터 업로드

## 준비
1. [taiko.wiki](taiko.wiki)에 로그인
2. [rating.taiko.wiki](rating.taiko.wiki)에서 프로필 생성(`/start`)
3. [동더히로바](https://donderhiroba.jp)에 로그인 후 카드 선택

## 1. 스크립트를 이용한 방법
1. 동더히로바에서 주소창에 아래 코드를 입력하고 실행
    ```
    javascript:(async () => {(new Function(await fetch('https://raw.githubusercontent.com/taikowiki/rating-taiko-wiki/refs/heads/main/upload-script/dist/index.js').then((r) => r.text())))()})();
    ```
2. 버튼을 눌러 업로드

    ![alt text](/docs/img/upload-1.png)

## 2. 확장 프로그램을 이용한 방법
1. [Donderhiroba Plus](https://chromewebstore.google.com/detail/donder-hiroba-plus/dmendcaacmlddhgalacgccejbamnncci) 크롬 확장을 다운로드.
    - 안드로이드 사용 시 [Kiwi Browser](https://play.google.com/store/apps/details?id=com.kiwibrowser.browser) 를 사용.
    - 아이폰을 사용 시, [Orion Browser by Kagi](https://apps.apple.com/us/app/orion-browser-by-kagi/id1484498200) 를 사용.
2. `Donderhiroba Plus` 열기.

    ![](/docs/img/upload-2.png)
3. `설정`을 클릭.

    ![alt text](/docs/img/upload-3.png)
4. `taiko.wiki Rating Upload` 를 클릭.

    ![alt text](/docs/img/upload-4.png)
5. `clear data + score data` 를 클릭 후 `Upload` 버튼을 클릭.

    ![alt text](/docs/img/upload-5.png)
6. 기다리기...
7. [레이팅 페이지](https://rating.taiko.wiki/myrating) 를 방문하여 레이팅을 확인.
