# 太鼓の達人 非公式レーティング (rating.taiko.wiki)

[rating.taiko.wiki](https://rating.taiko.wiki)は、アーケードゲーム「太鼓の達人」プレイヤーのデータを基に、実力を客観的なスコアとして数値化して表示する非公式レーティングサイトです。

## 目標

このプロジェクトの目標は、プレイヤーの実力を非公式レーティングを通じて定量的に示し、様々なデータ分析を提供することです。「ドンだーひろば」のプレイ記録に基づき、あなたの実力を精密に分析し、他のプレイヤーと比較することができます。

## 主な機能

- **レーティングスコアの計算**: 「ドンだーひろば」のデータを基に、ユーザーの総合的な実力を「レーティングスコア」として計算します。
- **曲別レーティングスコア**: 各曲のプレイ記録を基に「曲別レーティングスコア」を計算し、曲ごとの熟練度を把握することができます。
- **データ分析**: 算出されたレーティングスコアを活用した多角的な実力分析データを提供します。

## 収集するデータ

レーティング計算のために、以下のデータを収集します。

- **ドンだーひろばのプロフィール情報**
    - ニックネーム
    - 太鼓番（たいこばん）
    - 段位道場 合格情報
    - プレイ記録の概要
        - クリア数 / フルコンボ数 / 全良数（おに）
        - スコアランク別の王冠獲得数
- **曲のプレイ詳細データ**
    - 各曲のスコア、クリアの種類（王冠）、スコアランクなど
