# データアップロード

## 準備
1. taiko.wikiにログイン
2. rating.taiko.wikiでプロフィールを作成 (`/start`)
3. [ドンだーひろば](https://donderhiroba.jp)にログイン後、カードを選択

## 1. スクリプトを利用する方法
1. ドンだーひろばで、アドレスバーに以下のコードを入力して実行
    ```
    javascript:(async () => {(new Function(await fetch('https://raw.githubusercontent.com/taikowiki/rating-taiko-wiki/refs/heads/main/upload-script/dist/index.js').then((r) => r.text())))()})();
    ```
2. ボタンを押してアップロード

    ![alt text](/docs/img/upload-1.png)

## 2. 拡張機能を利用する方法
1. [Donderhiroba Plus](https://chromewebstore.google.com/detail/donder-hiroba-plus/dmendcaacmlddhgalacgccejbamnncci) Chrome拡張をダウンロード。
    - Androidユーザーは[Kiwi Browser](https://play.google.com/store/apps/details?id=com.kiwibrowser.browser)を使用。
    - iPhoneユーザーは[Orion Browser by Kagi](https://apps.apple.com/us/app/orion-browser-by-kagi/id1484498200)を使用。
2. `Donderhiroba Plus`を開く。

    ![](/docs/img/upload-2.png)
3. `設定`をクリック。

    ![alt text](/docs/img/upload-3.png)
4. `taiko.wiki Rating Upload`をクリック。

    ![alt text](/docs/img/upload-4.png)
5. `clear data + score data`をクリックした後、`Upload`ボタンをクリック。

    ![alt text](/docs/img/upload-5.png)
6. しばらく待つ...
7. [レーティングページ](https://rating.taiko.wiki/myrating)にアクセスしてレーティングを確認。
