# Introduction

## Goal
Quantifying user skills and analyzing data through unofficial ratings.

## Main Features
- Calculation of 'Rating Score' which quantifies user's skill through Donder Hiroba data.
- Calculation of 'Song Rating Score' based on individual song records.
- Analysis using rating scores.

## Data to be Collected
- Donder Hiroba Profile
    - Nickname
    - Taiko Number
    - Rank Certification Information
    - Play Record Summary
        - Clear / Full Combo / Donderful Combo Count
        - Number of badges according to score
- Song Play Data
