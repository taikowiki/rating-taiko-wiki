# Data Upload

## Preparation
1. Log in to taiko.wiki
2. Create a profile on rating.taiko.wiki (`/start`)
3. Log in to [Donderhiroba](https://donderhiroba.jp) and select a card

## 1. Using a script
1. In Donderhiroba, enter the code below into the address bar and run it.
    ```
    javascript:(async () => {(new Function(await fetch('https://raw.githubusercontent.com/taikowiki/rating-taiko-wiki/refs/heads/main/upload-script/dist/index.js').then((r) => r.text())))()})();
    ```
2. Press the button to upload

    ![alt text](/docs/img/upload-1.png)

## 2. Using an extension
1. Download the [Donderhiroba Plus](https://chromewebstore.google.com/detail/donder-hiroba-plus/dmendcaacmlddhgalacgccejbamnncci) Chrome extension.
    - If you are on Android, use [Kiwi Browser](https://play.google.com/store/apps/details?id=com.kiwibrowser.browser).
    - If you are on iPhone, use [Orion Browser by Kagi](https://apps.apple.com/us/app/orion-browser-by-kagi/id1484498200).
2. Open `Donderhiroba Plus`.

    ![](/docs/img/upload-2.png)
3. Click on `Settings`.

    ![alt text](/docs/img/upload-3.png)
4. Click on `taiko.wiki Rating Upload`.

    ![alt text](/docs/img/upload-4.png)
5. Click on `clear data + score data` and then click the `Upload` button.

    ![alt text](/docs/img/upload-5.png)
6. Wait...
7. Visit the [Rating Page](https://rating.taiko.wiki/myrating) to check your rating.
